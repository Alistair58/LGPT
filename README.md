###CS141 Functional Programming Coursework

The coursework was to implement a "chatbot" command line program in Haskell which could do basic functionality such as giving the current date, remebering a value, and evaluating a simple expression. As Haskell is a functional language, this is implemented through monads which store a parser state. Additionally, the coursework had an optional extension to implement anything you wanted into the chatbot. For this, I decided to give the chatbot the ability to compile programs in a basic programming language. A slight shoehorn but compilers fit in quite nicely with the theme of parsing. More information about the compiler is available in `report.pdf`. Note that the project structure and boilerplate code was provided - I did not write it all.
